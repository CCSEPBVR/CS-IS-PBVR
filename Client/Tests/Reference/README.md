# PBVR Client Test Reference Materials

このディレクトリには、PBVR クライアント GUI リグレッションテストを作成・更新するための参考資料を置く。

## ディレクトリ

- `ManualChecklist/`
  - 手動リグレッションテストの原本と、Codex が読みやすい変換済みファイルを置く。

- `Prompts/`
  - 初期移行時に使用する過去プロンプトを置く。
  - 通常の新規テスト作成では、まず `AGENTS.md`、`REGRESSION_TEST_COVERAGE.md`、手動チェックシート、既存テストコードを参照する。

- `Reports/`
  - 過去に生成されたテストレポートを置く。
  - Markdown レポート形式やスクリーンショット構成の参考にする。

- `Movies/`
  - スクリーンショットだけでは分かりづらい GUI 動作の参考動画を置く。

## 注意

- このディレクトリの資料は参照用であり、通常のテスト実行結果ではない。
- 新しくテストを実行した結果は `Client/output-tests/` に保存する。
- 明示的な指示がない限り、原本資料を上書きしない。
