# KVS

このディレクトリは PBVR が利用する KVS ライブラリを扱う。

## ビルド

ユーザーから別の指示がない場合は、`KVS` ディレクトリを基準として以下を実行する。

```sh
make -j $(nproc)
```

単列確認が指定された場合は、続けて `make` を実行する。

## 実装上の注意

- KVS のコンパイル失敗後に発生する `library 'kvsCore' not found` は二次エラーの可能性があるため、最初のコンパイルエラーを優先して調査する。

## 成果物

ビルド後に KVS ライブラリが `KVS/Install/lib` に生成されることを確認する。
